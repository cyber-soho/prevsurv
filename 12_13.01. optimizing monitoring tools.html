Lecture 1: Taming the Noise

Tuning does not remove real threats—it removes the junk so the real ones become visible. Use "The Four Levers" below to transform raw events into meaningful security stories.

Deduplicate

Fold identical alerts in a time window into one. Don't page 200x for one event.

Correlate

Group related alerts (e.g., password spray) into a single incident story.

Threshold

Define "how much is too much." Balance triggers to avoid false-positive storms.

Severity

Rank incidents so human analysts tackle the worst, highest-risk items first.

Interactive Tuning: False Positives vs. Negatives

The Allowlist Scalpel

Trust a specific source for a specific rule. Never trust an IP for everything.

The Suppression Rule

Mute narrow, known-benign patterns (e.g., AV test files) to keep the channel clear.

Golden Rule: Good tuning is provable. Ensure real attacks still fire after your change.
